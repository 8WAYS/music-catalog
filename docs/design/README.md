# Дизайн-макеты

Исследования и макеты визуала. Каждая версия — отдельный HTML-файл: открывается в браузере без сборки.

| Файл | Что внутри |
| --- | --- |
| `cd-design-v1.html` | Первое исследование CD-эстетики: три направления (джевел-кейс, голограмма, прозрачный пластик), семь анимаций, удобство, цена эффектов |
| `cd-design-v2.html` | Направление «Перламутр и стекло» (голограмма + пластик), приглушённый перелив диска, два варианта «Удиви меня»: перебор полки и лоток плеера |
| `cd-design-v3.html` | Тёмная тема «Графит и стекло»; «Удиви меня» — Hi-Fi дека: лоток под 8/12 см, флуоресцентный дисплей, кнопки, корпус серебро/графит |
