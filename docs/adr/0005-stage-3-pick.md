# ADR 0005. Решения этапа 3 (главная и подбор)

Статус: принято · 2026-09-25

1. **Фильтры — в адресе, и только там.** `#/?tags=осень,вечер&q=кино&sort=year` — единственный источник состояния
   главной (`routeQuery` в `src/router.ts`); ссылкой на выборку можно поделиться, «Назад» с карточки возвращает
   к той же выборке. Параметр по умолчанию (`sort=added`) в адрес не пишется.
2. **Теги в адресе — по именам, не по UUID**: ссылку можно прочитать и набрать руками. Имена уникальны без учёта
   регистра (ADR 0002, п. 5); сравнение — через `normalize` (регистр, ё/е). Имена разделяются запятой, запятая внутри
   имени кодируется `%2C`. Незнакомые имена пропускаются. Цена: переименование тега ломает старые ссылки на выборку —
   для личной картотеки приемлемо.
3. **Смена фильтров не создаёт записей в истории** (`replaceHash`): иначе каждый символ в поиске — лишний шаг «Назад».
   Переход с тега на карточке (`navigate`) — новая запись, чтобы «Назад» вёл обратно на карточку.
4. **Лента чипов показывает только теги, дающие непустой результат** вместе с уже выбранными (выбранные видны всегда).
   Так в пересечении нет тупиков, и лента короче. Порядок: по группам (настроение → жанр → место → время → другое),
   внутри — по частоте в текущей выборке.
5. **Поиск**: все слова запроса должны встретиться в названии, исполнителе, описании или треках, в любом порядке.
   Нормализованный текст релиза кэшируется в `WeakMap` по объекту релиза — при изменении релиз заменяется новым
   объектом, и кэш сбрасывается сам. На 1 000 релизов индекс не нужен.
6. **Сортировка по названию — русский словарный порядок** (`Intl.Collator('ru')`): кириллица перед латиницей,
   ё сравнивается как е. По году — новые сверху, релизы без года в конце.
7. **«Удиви меня»**: 3 случайных кадра из текущей выборки без повторов подряд, затем выбранный; вся анимация 800 мс.
   При уменьшении движения (системная настройка или переключатель в настройках) и при выборке из одного релиза —
   сразу карточка.
