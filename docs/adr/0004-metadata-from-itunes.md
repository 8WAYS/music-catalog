# ADR 0004. Метаданные и треклист из iTunes вместо MusicBrainz

Статус: принято · 2026-09-25 · заменяет MusicBrainz из разделов 5 и 12 спецификации

## Контекст

Проверка этапа 0 (ADR 0001): из домашней сети владельца MusicBrainz отвечает только с VPN, без VPN запрос висит.
iTunes Search API работает в обоих режимах и уже выбран для обложек (ADR 0003). Требование владельца —
добавление альбомов с VPN и без.

## Решение

Автозаполнение на этапе 4 целиком из iTunes — один сервис вместо двух:

- поиск: `https://itunes.apple.com/search?term=<исполнитель> <альбом>&entity=album&limit=10`;
- альбом и треклист: `https://itunes.apple.com/lookup?id=<collectionId>&entity=song` — первая запись альбом
  (`collectionName`, `artistName`, `releaseDate`, `primaryGenreName`, `artworkUrl100`), дальше треки
  (`trackNumber`, `discNumber`, `trackName`, `trackTimeMillis`);
- обложка — `artworkUrl100` с размером `600x600bb` (ADR 0003);
- оба адреса отдают `Access-Control-Allow-Origin: *` (кроме страниц с `Origin: null`), ключ не нужен.

Сопоставление полей:

- тип релиза: `collectionName` оканчивается на « - EP» → EP, « - Single» → сингл, иначе альбом;
  суффикс из названия убираем;
- год — первые 4 символа `releaseDate`;
- жанр — подсказка для тега (группа «Жанр»), не ставится автоматически;
- `trackTimeMillis` → длительность «м:сс».

Витрину (`country`) выбирать по языку запроса: кириллица → `RU`, иначе `US`; если пусто — повторить с другой.
Лимит iTunes — порядка 20 запросов в минуту: поиск запускать по кнопке или с паузой после ввода, не на каждую букву.

## Последствия

- Каталог — только то, что есть в Apple Music: редких изданий, бутлегов и самиздата может не быть → ручной ввод
  остаётся полноценным путём.
- Поле `Release.mbid` (не используется) на этапе 4 заменить на `itunesId` (`collectionId`):
  `FORMAT_VERSION` 1 → 2, миграция в `src/data/migrations.ts` и тест.
- Экран `#/add` — поиск по iTunes; «О приложении» — источник данных iTunes.
- Сообщение об ошибке сети — человеческое («iTunes не отвечает, попробуй позже»), не «Load failed».
- MusicBrainz можно вернуть позже как второй источник для редких релизов (с VPN) — сейчас не делаем.
