# ADR 0001. Проверка внешних сервисов (этап 0)

Статус: принято · 2026-09-25 · не проверены Android и мобильная сеть

## Контекст

Первая версия работает без своего сервера: MusicBrainz, iTunes (обложки, ADR 0003) и GitHub вызываются прямо
из браузера (разделы 5 и 12 документации). Нужно убедиться, что каждый сервис отвечает с телефона из РФ,
или выбрать запасной путь.

Требование владельца: добавление альбомов должно работать **и с VPN, и без него**; в крайнем случае — хотя бы
в одном из режимов. Отказоустойчивость с перебором источников пока не строим.

## Как проверялось

Страница `app/public/probe.html` на GitHub Pages, iPhone (iOS 26.1, Safari), **домашний Wi-Fi** — мобильный интернет
недоступен. Два прогона: с VPN и без; AdGuard выключен (с ним запросы из Safari падали с «Load failed»).
Таймаут каждого запроса — 20 с.

Не проверено: Android (Chrome) и мобильная сеть. Друзья-зрители будут смотреть в основном с мобильного —
перед запуском (этап 8) попросить кого-нибудь открыть probe.html через мобильный интернет без VPN.

## Результаты

| Сервис | Без VPN | С VPN | Решение |
| --- | --- | --- | --- |
| MusicBrainz, поиск и треклист | ❌ таймаут, ответа нет | ✅ | отказались, метаданные из iTunes (ADR 0004) |
| iTunes, поиск + обложка 600×600, CORS + canvas | ✅ | ✅ | обложки из iTunes (ADR 0003) |
| Canvas → WebP | ❌ Safari отдаёт PNG | ❌ | подтверждено: в Safari сохраняем JPEG (ADR 0002) |
| GitHub Git Data API, коммит | ✅ коммит 8996cf9 | ✅ коммит 10c45d5 | публикация прямо из браузера (этап 5) |
| GitHub Pages, отдача data/ | ✅ | ⚠️ с перебоями: раз таймаут, раз открылось | см. ниже |

Cover Art Archive (первый прогон, до ADR 0003): без VPN работал, с VPN — нет (редирект на archive.org).

Дополнительно проверено с компьютера: iTunes `lookup?id=<альбом>&entity=song` отдаёт треклист (номер, название,
длительность), год и жанр с `Access-Control-Allow-Origin: *`; русский каталог есть (`country=RU`: «Группа крови» — Кино).

## Шрифты

Unbounded (заголовки) + Onest (текст): полная кириллица, переменное начертание, OFL, файлы раздаются с того же
домена (пакеты @fontsource-variable, собираются Vite). Утвердить по виду на телефоне.

## Решение

1. **Обложки — iTunes** (ADR 0003): работает в обоих режимах.
2. **Публикация — GitHub Git Data API** из браузера по fine-grained токену (Contents: Read and write) — работает в обоих режимах.
3. **Зрители — GitHub Pages.** Через VPN владельца Pages отвечает нестабильно, поэтому на этапе 5: у запроса
   `data/catalog.json` таймаут и повтор, при неудаче — последняя сохранённая версия и понятное сообщение.
4. **Метаданные и треклист — iTunes** (ADR 0004): MusicBrainz доступен только с VPN, iTunes — в обоих режимах.
5. Сетевые ошибки в приложении показывать по-человечески («Сервис не отвечает — попробуй с VPN или без»),
   а не «Load failed».
