# ADR 0001. Проверка внешних сервисов (этап 0)

Статус: **в работе** · 2026-09-25

## Контекст

Первая версия работает без своего сервера: MusicBrainz, iTunes (обложки, ADR 0003) и GitHub вызываются прямо
из браузера (разделы 5 и 12 документации). Нужно убедиться, что каждый сервис отвечает с телефона из РФ через мобильную сеть,
или выбрать запасной путь.

## Как проверялось

Страница `app/public/probe.html` на GitHub Pages, открыта с iPhone (Safari) и Android (Chrome) через мобильную сеть.
